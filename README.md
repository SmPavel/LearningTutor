## README для проекта

### Умный репетитор (Smart Tutor)

**Краткое описание:**  
Мобильное приложение для персонализированного обучения с адаптивной генерацией вопросов на основе алгоритмов машинного обучения. Подстраивается под уровень знаний пользователя в реальном времени, используя модели Item Response Theory (IRT) и интервального повторения (SM-2).

**Ключевые возможности:**
- Оценка уровня знаний пользователя (θ) по модели Раша
- Интервальное повторение для долгосрочного запоминания
- Генерация уникальных вопросов через LLM (OpenRouter.ai)
- Персонализированные рекомендации и визуализация прогресса
- Offline-режим: fallback на локальные вопросы

**Стек:**
- Kotlin, Jetpack Compose, Material 3
- Clean Architecture + MVVM
- Room (SQLite), Hilt (DI)
- Coroutines + Flow
- OkHttp + Moshi (OpenRouter.ai API)

**Архитектура:**  
Clean Architecture с 4 слоями: Presentation (UI + ViewModel), Domain (модели + алгоритмы IRT/SM-2), Data (репозитории + Room + API), DI (Hilt).

**Как работает:**
1. Пользователь выбирает тему → система подбирает вопрос под его уровень
2. Ответ → обновление θ через IRT и расписания через SM-2
3. Если вопросов нет — генерация через OpenRouter.ai (с fallback)
4. Статистика отображается в реальном времени

**Статус:**  
Прототип готов, протестирован на реальных устройствах.
